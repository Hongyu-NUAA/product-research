RSSI — 接收信号强度指示

RSSI（Received Signal Strength Indicator） = 接收端"收到的信号有多强"的指示量，单位 dBm。无线链路是双向的，因此通常分"飞机端 RSSI / 遥控端 RSSI"分别记录。

  • 数值越大信号越强：-40dBm 远强于 -80dBm（dBm 是负值，见下方专条）
  • max / min：被测设备旋转/移动一周内收到的最大与最小信号，反映稳定性
  • 量级判断：-30~-60dBm 属强信号区间；-90~-110dBm 已逼近接收机灵敏度下限
⚠️ 报告记录的"绝对值陷阱"：部分测试表把负号省掉、只记绝对值（如 58 代表 -58dBm），此时数字越小反而信号越强，阅读前必须先补负号；正式报告建议统一为标准 -dBm 格式，避免误读。

不圆度 — 天线的方向均匀性指标

不圆度 = 天线旋转一周内最强信号与最弱信号的差值（max − min，单位 dB）。天线并非完美球形，向四周接收信号的能力有强有弱。

  • 数值越小越好：各方向接收均匀，像标准圆；设备转身信号不掉
  • 数值大：存在明显"死角"，设备姿态一变信号就大幅波动
  • 典型量级：优质天线不圆度在 2~7dB 以内

MCS 档位 与 链路速率

无人机图传/遥控链路为适应信号好坏，会自动在多个传输模式（MCS 档位）间切换：

  • 档位越高 = 每帧携带数据越多（更高阶调制、更高码率），但要求信号越好；信号差时自动降档保连接
  • 速率（Mbps） = 链路实际传输速度；档位决定上限、信号决定实际值
  • "档位高但速率低" = 档位已爬升但吞吐上不去，通常意味着重传严重（丢包/干扰/链路质量差）

dBm 与 dB — 为什么接收信号是负值

dBm 的"0"是 1 毫瓦基准线：

# dBm 定义：功率相对 1mW 的分贝数
dBm = 10 × log10( P / 1mW )
# P = 1mW  →  0 dBm（基准点）
# P > 1mW  →  正数（如 +20dBm = 100mW，发射端）
# P < 1mW  →  负数（接收端，常为 1mW 的百万分之一量级）

接收信号功率远小于 1mW，所以 dBm 天然为负。对数刻度两大理由：

  • ① 动态范围横跨 12+ 个数量级，线性刻度画不下
  • ② 衰减是乘法（自由空间每远一倍功率 ×1/4），对数变为每远一倍 −6dB，链路预算整条是加减法：接收(dBm) = 发射(+20) − 路径损耗(80) = -60dBm
概念含义典型值
dBm以 1mW 为基准的功率刻度发射 +20 / 接收 -60~-100
dB两个量的差值（不圆度、衰减）3dB=2倍 / 6dB=4倍 / 10dB=10倍

接收灵敏度 — 接收机的"听力门槛"

灵敏度 = 接收机还能正确解调出信号的最低电平，是"听不见"的门槛，典型约 -90 ~ -110 dBm。

  • 数值越低（越负）越好：能听到更弱的信号，通信距离更远
  • 信号低于灵敏度时，速率骤降、误码/断链风险激增

有源 vs 无源天线/模块

一句话：无源 = 不插电的"传话筒"，只传递不放大；有源 = 插电的"助听器"，内置放大器（LNA）把微弱信号放大后再输出。

维度无源（被动）有源（主动）
供电不需要需要（馈线/电源供电）
放大能力无，信号原样传递内置 LNA，可增强信号
灵敏度受限于接收机本身更高，能"听"到更弱信号
噪声不引入额外噪声放大器自身引入噪声（噪声系数 NF）
典型应用收音机天线、WiFi 贴片天线GPS 有源天线、卫星电视锅、射频 hub 模块
⚠️ "放大器虚高"原则：加了 LNA 的有源设备，其 RSSI 读数是被放大过的值（同一真实 -80dBm 可能显示 -60dBm）。因此有源设备的 RSSI 只能看相对趋势，不能与无源设备横向比绝对值。射频设计铁律："最好的放大器是放在最前面的放大器"——LNA 越靠近天线，系统灵敏度提升越明显。

屈服强度 vs 抗拉强度

屈服强度 σs 是材料"开始不可逆变形"的门槛；抗拉强度 σb 是材料"被拉断前能承受的最大应力"。正常材料必有 σs < σb。

# 应力-应变曲线四阶段
应力
 ↑        抗拉强度 σb (峰值)
 │          ╱↘
 │         ╱   ↘ 颈缩 → 断裂
 │        ╱
 │───────╱────── 屈服强度 σs (拐点/平台)
 │      ╱
 │     ╱  弹性段（卸载可恢复）
 └────────────────→ 应变
  • 弹性段：低于屈服强度，卸载后完全恢复原状
  • 屈服点：进入塑性，变形不可逆（"掰弯松手回不直"）
  • 强化段：加工硬化使材料能承受更大应力，直到抗拉强度峰值
  • 颈缩段：过峰值后局部变细、迅速断裂
📌 工程要点：① 结构设计以屈服强度为准——超过即永久变形失效；② 屈强比 σs/σb 越小安全缓冲越大，接近 1 偏脆；③ 铝合金等无明显屈服平台的材料用条件屈服强度 σ0.2（产生 0.2% 塑性应变对应的应力）；④ 纤维增强塑料（PA+GF / PA+CF）通常没有明显屈服平台，物性表给出的多为抗拉（断裂）强度，表述时注意区分。

弹性模量 vs 弯曲模量

项目含义测试标准
弹性（拉伸）模量材料拉伸时的刚度（应力/应变）ISO 527-2
弯曲模量材料弯曲时的刚度ISO 178
  • 金属：两者数值接近，可近似互换
  • 玻纤/碳纤增强塑料：弯曲模量往往明显高于拉伸模量（弯曲时存在应力梯度、受压侧与纤维取向影响），严格不能直接替代
  • 物性表只提供弯曲模量时，按拉伸模量使用需注明"由弯曲模量估算"
