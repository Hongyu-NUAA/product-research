3.3 交互流程

flowchart LR subgraph 交互流程 A[抬起唤醒] -->|拿起即醒| B[入口启动] B -->|接触牙齿| C[动力渐强 3s] C --> D[正常扫振] D -->|倒置 70°| E[自清洁甩干] end subgraph 安全保护 F[过压检测] -->|力度过大| G[自动停振+提醒] H[飞行模式] -->|差旅防误触| I[关闭感应] end

核心功能列表

  1. 抬起唤醒 — 拿起自动唤醒，无需按键
  2. 入口启动 — 刷头感应压力后才启动，不甩牙膏
  3. 动力渐强 — 启动后 3 秒逐渐增强，牙龈有适应时间
  4. 三挡过压提醒（±30g 精度）— 用力过大自动停振
  5. 双模式 — 舒适模式 / 深度模式（PID 补偿开关）
  6. 倒置自清洁 — 倾斜 70° 自动高速空转甩干刷毛
  7. 充电底座 = Qi 无线充 — 可为 AirPods / iPhone 应急充电
  8. 两年只换不修 — 售后承诺

五、设计与用户体验

5.1 外观设计

  • 设计语言： 极简主义，"苹果设计风格"
  • 四种材质： ABS / 高透 PC（AF 涂层）/ 铝合金 / 不锈钢
  • 透明探索版： 渐变透明机身，可见内部电机结构
  • 无缝压感按键： 内凹设计，不藏污纳垢
  • 不锈钢款： 连续拉伸一体成型，镜面抛光

5.2 用户交互

  • 交互逻辑： 无实体按键 + 抬起唤醒 + 入口启动，零操作门槛
  • 充电体验： 磁吸无线充电，"咔哒"吸附即充
  • 底座拓展： 可当 Qi 无线充电器用（15W），出差少带一个充电器

十、SWOT 分析

优势 Strengths

  • 扫振式技术路线差异化明显，开创品类
  • 自建超级工厂，核心部件 80%+ 自产
  • 苹果风格设计，用户自发传播
  • 市场份额 16%，第一梯队
  • 两年只换不修售后

劣势 Weaknesses

  • 产品质量不稳定，充电故障频发
  • 品牌口碑恶化，负面占 21.28%
  • 刷头涨价 + 换新活动引发信任危机
  • 牙刷年亏 8000 万
  • 研发投入仅 3.5%（营销 42%）
  • 高管集体流失

机会 Opportunities

  • 渗透率 25%，仍有翻倍空间
  • 亚太 CAGR 7.9%，全球最快
  • 线下 300 家门店扩张
  • "3+N" 战略拓展品类
  • 高端化趋势

威胁 Threats

  • 小米/追觅价格战
  • 与戴森专利纠纷，海外受阻
  • 负面口碑传导
  • 技术路线可能被复制
  • 增长放缓，618 同比 -40%
  • 重资产扩张 + 亏损 = 资金链风险

核心结论

徕芬 i2 技术创新领先、设计出色，但品控和用户运营存在明显短板。公司层面面临增长放缓（618 GMV -40%）、核心品类亏损（牙刷年亏 8000 万）、高管集体流失、品牌信任透支的多重压力。

可借鉴点

  1. 技术+设计的差异化突围： 在红海品类中找到"扫振式"技术空白，配合苹果系设计语言
  2. 垂直整合降本： 自建超级工厂，核心部件自产，长期成本可控
  3. 充电底座一物多用： 通用 Qi 无线充，解决痛点
  4. 无感交互： 抬起唤醒 + 入口启动 + 倒置自清洁
